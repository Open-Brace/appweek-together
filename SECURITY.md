# Security

Report vulnerabilities privately using [GitHub's security advisory form](https://github.com/Open-Brace/appweek-together/security/advisories/new). Do not put credentials, session cookies, recovery codes, invite links, or private user data in public issues.

Include the affected version, reproducible steps using test accounts you control, and the impact. Test only your own deployment and data. Do not access another group's information or run destructive checks against the hosted app.

The main branch is the currently maintained version. There is no guaranteed response time or long-term support commitment.
